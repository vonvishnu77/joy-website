# The Final Divide

A cinematic, BLEACH: Thousand-Year Blood War-inspired fan concept built as a responsive, dependency-free landing page.

## Preview locally

No build step or package installation is required.

1. Clone the repository.
2. Open `index.html` in a browser, or serve the folder with any static HTTP server.
3. For example, with Python installed, run `python -m http.server 8000` from the project directory and open `http://localhost:8000`.

## Features

- Dark cinematic art direction with crimson energy, animated rings, blade-slash lighting, grain, and floating particles.
- Responsive layout for desktop, tablet, and mobile.
- Interactive Soul Reaper / Quincy / Hollow faction selector with keyboard arrow navigation.
- Scroll progress indicator and reveal-on-scroll transitions.
- Respects the operating system's reduced-motion preference.
- Semantic landmarks, keyboard focus indicators, and accessible tab/status labels.
- No JavaScript framework or runtime dependencies. Google Fonts are optional external assets.

## Notes

This is an independent fan-made concept and is not affiliated with the BLEACH rights holders. It uses original CSS-driven visuals and text rather than bundling official anime artwork.
